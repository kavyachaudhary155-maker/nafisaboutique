# Nafisa Boutique Storefront

This project has been rebranded for Nafisa Boutique in Brampton, Ontario.

- Brand direction: deep navy, warm gold, and ivory, with the supplied Nafisa emblem.
- Homepage: boutique-focused hero, 3D-style collection CTA, featured sarees, story section, and Instagram link.
- Store: seven supplied saree photographs, product detail views, cart, and a local demonstration checkout/tracking flow.
- Product prices are intentionally shown as **Price on request** because no prices were supplied. Customers can enquire through the Instagram profile link.
- Checkout and order tracking are demo-only browser features. No real payment is collected and no courier integration is connected.

Deploy the project using the existing Vite/Vercel configuration.
